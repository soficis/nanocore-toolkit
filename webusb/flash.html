Nanocore OS 1.2 UniVibe flash

Write path. Replaces VELVET VIBRATO with UNIVIBE on firmware 1.2. Default state is a dry run.

This page can erase and rewrite the pedal's OS

  • Do not run Stage 2 until Stage 0 passes and you have read the plan it prints.
  • ToneCommand must be closed and the audio / headphone cable unplugged.
  • Do not unplug the USB cable during a write. An interrupted write leaves the pedal sitting in its update-mode bootloader; it is recovered by reading it again or by the official updater, not by retrying blindly.
  • One attempt only. This page never retries on its own.
  • The build is not proven safe: see "Still unproven" in README.md.

Stage 0 Plan only — no USB

Pick the three local files. Nothing is fetched from a server and no USB object is created in this stage. The page hashes both images and lists the exact 64 KiB sectors that would be erased.

Erase plan

    Final partial sector is a separate, short region. It is not a whole 64 KiB sector, so the writer refuses to touch it; this build does not change it.

    Stage 1 Enter update mode

    Sends the bootloader request over MIDI (SysEx F0 7D 44 46 55 01 F7) and waits 1200 ms. The pedal re-enumerates as an update-mode USB device. Allow MIDI access when asked.

    Stage 2 Flash

    Available only after Stage 0 passes. Before the first USB call the page re-checks both images against the build hashes and re-authenticates the patched image, then program() byte-compares the live partition with the stock readback and saves a verified pre-flash backup before erasing anything.
