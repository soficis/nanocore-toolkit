Nanocore firmware readback

Read-only. This page downloads a copy of the pedal's firmware. It never writes to the pedal.

Read this first

  • This only reads the pedal. Nothing is written, erased or verified by this page.
  • ToneCommand must be closed before you start, otherwise it holds the MIDI and USB device.
  • Physically unplug the audio / headphone cable from the pedal. Keep the USB cable in.
  • Do not unplug the USB cable while the read is running. Wait for the progress bar to finish.
  • Step 1 puts the pedal into its update-mode bootloader. That is the same mode the official app uses to install firmware.

Step 1 Enter update mode

Sends the bootloader request over MIDI (SysEx F0 7D 44 46 55 01 F7), then the pedal re-enumerates as an update-mode USB device. Allow MIDI access when the browser asks.

Step 2 Read firmware (read-only)

Pick the 33c3:6678 NanoCore device in the browser dialog, then the full OS partition (868,352 bytes) is read in 4,096-byte blocks. Leave the pedal alone until it finishes.
